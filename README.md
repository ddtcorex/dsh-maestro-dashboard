# dsh-maestro-dashboard

Maestro Dashboard — unified Control Center (Overview/Plugins/Usage) DSH-native

> DSH Maestro plugin — part of the `dsh-maestro-*` ecosystem (`@ddtcorex/dsh-maestro-dashboard`).

## Install

```sh
dsh plugin add @ddtcorex/dsh-maestro-dashboard
```

## Develop

```sh
pnpm --filter @ddtcorex/dsh-maestro-dashboard verify
pnpm --filter @ddtcorex/dsh-maestro-dashboard build
```
